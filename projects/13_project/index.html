Combining graph data and time series data to unlock new analytical workflows

LIRIS, Lyon 1 University — Villeurbanne, France · 01/10/2024 – present

The focus of my PhD is the combination of graph data and time series data to discover new insights and unlock analytical workflows that were previously impossible when these data types were treated in isolation.

More specifically, my work consists of:

  • Defining a data model that integrates both graph data and time series data.
  • Developing efficient storage mechanisms to minimize memory overhead and enable fast data retrieval.
  • Designing algorithms that leverage both data types to create new analytical workflows.
